按顺序读，别跳
    01 先想清楚：这条路怎么走 这门课能带你到哪里、每天两小时怎么分配、手机和电脑各自负责什么，以及一份不容易半途而废的节奏表。 未开始 02 变量与数据类型 从「给数据起名字」讲起，把 let/const、七种原始类型、null 与 undefined、typeof 的坑、类型转换和 0.1 + 0.2 一次讲透。 未开始 03 运算符与表达式 从取余的真实用途讲到短路求值、空值合并与逻辑或的差别、优先级陷阱，把 JS 运算符一次讲清。 未开始 04 流程控制：条件与循环 if 与 switch 怎么选、for 的三段式怎么执行、break 与 continue 的边界，以及死循环是怎么来的。 未开始 05 函数：把逻辑装进盒子 三种函数写法怎么选、参数与返回值的真实规则、回调为什么到处都是，以及纯函数与递归的用法。 未开始 06 数组与常用方法 从下标和增删讲起，分清 splice 与 slice，再把 map、filter、reduce、sort 练熟。 未开始 07 对象与 JSON 把一组相关数据装进对象，讲清属性访问、遍历、解构、浅拷贝与深拷贝，以及 JSON 转换时悄悄消失的字段。 未开始 08 字符串、Math、Date 与正则 模板字符串与常用方法、Math 取整与随机数、Date 的时区坑，以及只做格式校验的正则入门。 未开始 09 作用域、闭包与变量提升 变量到底住在哪里，为什么循环里的回调总打印同一个值，闭包能做什么、什么时候会拖住内存。 未开始 10 this 到底指向谁 用「看调用方式，不看定义位置」一句口诀，讲清五种调用场景、this 丢失的经典 bug，以及 call/apply/bind 的区别。 未开始 11 原型链与 class 从「方法为什么要共享」讲起，拆开 prototype、constructor、__proto__ 的关系，再把 class、继承、私有字段和 new 的过程讲透。 未开始 12 ES6+ 必会语法 解构、展开、模板字符串、默认参数、可选链、Set 与 Map、for...of，把现代 JS 里每天都会遇到的写法一次讲透。 未开始 13 异步：回调、Promise、async/await 从单线程为什么会被卡住讲起，用事件循环、Promise 三种状态和 async/await 把「等」这件事彻底说清。 未开始 14 模块化与 npm 从全局变量互相覆盖讲起，把 ESM 与 CommonJS 的写法、package.json 每个字段、npm 命令和版本号规则一次说清。 未开始 15 DOM 与事件 从「浏览器把 HTML 变成树」讲起，学会选中、改写、增删页面元素，再用事件、冒泡与委托让页面真正响应操作。 未开始 16 浏览器存储与网络请求 把数据留在浏览器里，再用 fetch 从服务器取回来：localStorage 与 JSON 封装、HTTP 状态码、超时取消、CORS 与加载三态界面的完整写法一次讲清。 未开始 17 错误处理与调试 读懂四类常见报错与调用栈，掌握 throw、try/catch/finally 和异步错误的处理方式，再用断点与 Network 面板把 bug 快速定位到具体一行。 未开始 18 实战：写一个待办清单 从需求拆解到五个可运行版本，把表单、事件委托、筛选与 localStorage 组装成一个刷新不丢的待办清单。 未开始 19 从脚本到工程 把三个文件的练手项目变成可维护的工程：目录职责、npm 脚本、Vite 构建、代码规范、Git 版本管理与静态部署的完整流程。 未开始 20 下一步：TypeScript、Node 与小程序 学完 JS 之后往哪走：用 TypeScript 提前发现错误、用 Node 写第一个接口、用小程序把作品装进微信，并给出三个月路线与项目清单。 未开始

把课程装到手机上

iPhone / iPad

用 Safari 打开本页，点底部「分享」按钮，选择「添加到主屏幕」。之后从桌面图标进入，全屏阅读、可离线。

Android

用 Chrome 打开本页，右上角菜单里选择「添加到主屏幕 / 安装应用」。第一次打开后所有章节会缓存到本机，地铁里没信号也能读。

进度是怎么记录的

进度保存在当前浏览器的本地存储里：每章的已读状态、上次滚动位置、最后打开的章节。换设备或清理浏览器数据会丢失，所以可以在上面「进度备份」里导出 JSON，换设备后导入。

手机和平板各记各的进度，互不影响。

建议节奏：通勤读 1 章，晚上在电脑上把练习敲一遍。
